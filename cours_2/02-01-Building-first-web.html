The windows you will use

Claude Code + your file manager

Claude Code changes your files. Finder on Mac or File Explorer on Windows shows where they are.

Your web browser

Chrome, Edge or Safari displays the page. Later, the browser also opens GitHub.

A folder holds the project files

Folder

A container, like a bag. We will name ours campus-lunch.

File

One item inside the folder. index.html will be the page that you open.

A project is the folder and the files that belong to this website.

The ending of a filename matters

index.html

The .html ending tells us it is a web document. Keep the full name when saving or uploading.

style.css and app.js

These files control appearance and behavior. Claude Code will create them for us.

A filename is different from the title shown inside the page.

GitHub is a home for your project

Repository = project storage

An online place for one project’s files and saved versions.

GitHub Pages = published website

A service that turns those files into a page other people can open.

We will use GitHub in the browser. No Git commands are needed.
