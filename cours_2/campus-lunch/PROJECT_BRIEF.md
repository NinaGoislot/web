# Campus Lunch

Build a small English webpage for students choosing lunch.

## Core workshop

Use index.html, style.css and app.js. Plain HTML, CSS and JavaScript only. Use the sample data in menu-data.json; keep it in app.js so opening index.html directly works without fetch or a server. Start with Monday's three meals. Later add a day selector and a Vegetarian only checkbox.

White background, black text, thin gray card borders, generous space. Meal cards show name, description, price in KRW and dietary label. Use semantic elements, labeled controls, keyboard access and a useful empty message. At 390px wide, stack cards vertically without horizontal scrolling.

No account system, ordering, payment, database, external images or build tools are needed for this exercise.

## Expected examples after the interaction step

- Monday / filter off: 3 meals.
- Monday / vegetarian on: Bibimbap and Tofu bowl (2 meals).
- Tuesday / vegetarian on: Mushroom pasta and Lentil soup (2 meals).
- Wednesday / vegetarian on: 0 meals and a readable empty message.
- Wednesday / filter off: 3 meals.

All prices and menus are classroom sample data. They are not a real cafeteria menu.
